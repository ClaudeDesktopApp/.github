# Claude Desktop App 🤖💻

**Claude Desktop App** is the native Windows client for Anthropic's AI assistant, built around three working modes that cover the whole day: **Chat** for conversations and research, **Cowork** for longer agentic tasks and dispatch work, and **Code** for software development with parallel sessions, visual diffs, and app previews. It connects to local files and tools through MCP servers, links to GitHub, Slack, and Linear, and keeps conversation history synced with the web app under the same account.

## ⚡ Quick Start

1. Download the Windows installer from the button above.
2. Run the installer as Administrator and complete setup.
3. Launch Claude from the Start menu and sign in with your account.

The app opens with the **Chat** tab active; **Cowork** and **Code** are available from the top navigation.

## ✨ Key Features

**Chat**

- 💬 **Conversation Workspace** — native desktop chat with file uploads, image and PDF attachments, and conversation history synced from the web app.
- 📎 **File Context** — attach documents directly or @mention local files so Claude can read and reference them in the conversation.
- 🔎 **Web and Research** — ask questions that pull from the web and from your attached context in the same thread.

**Cowork**

- 🧠 **Longer Agentic Tasks** — dedicated space for multi-step work that runs beyond a single reply.
- 📲 **Dispatch Sessions** — send tasks from your phone and pick them up in the desktop app.
- 🔁 **Persistent Context** — Cowork sessions keep their own history independent of Chat threads.

**Code**

- 🧩 **Parallel Sessions** — each session has its own chat history, project folder, and code changes, isolated from the others.
- 🔀 **Git Worktree Isolation** — sessions run in separate worktrees so multiple changes do not collide.
- 👁️ **Visual Diff Review** — review, comment, and approve changes line by line before committing.
- 🖥️ **App Preview** — preview the running app in a browser pane while Claude verifies its own changes.
- 🧭 **Drag-and-Drop Panes** — arrange chat, diff, browser, terminal, and file editor side by side.

**Connectors & Local Tools**

- 🔌 **MCP Server Support** — connect local Model Context Protocol servers to give Claude controlled access to your filesystem, Git, and other tools.
- 🐙 **GitHub Connector** — link repositories, issues, and pull requests through GitHub's hosted MCP server or a local connector.
- 💬 **Slack and Linear** — pull team context and task tracking into the same workspace.
- 🖱️ **Computer Use** — let Claude open apps and control your screen with per-action permission.

## ❓ FAQ

**Do I need to run the installer as Administrator?**
Administrator rights are recommended for installation so the app can register correctly on Windows.

**Will my antivirus flag the file?**
If a heuristic flags the installer, verify the publisher and add the folder to exclusions if needed.

**Does it work on Windows 11?**
Yes — Windows 10 and Windows 11 (64-bit) are supported.

**Do I need a paid plan?**
Chat works with a free account; Code and Cowork require a paid plan.

**How do I update?**
Use the in-app update check from the Claude menu, or download the latest installer using the button above.
